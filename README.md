# Illust Shelf for iOS

Browse and organize illustrations in a folder, with tags, sources, and notes. An iPhone and iPad version of [Illust Shelf](https://github.com/xiupos/illust-shelf-gtk): the same folder works with both, since the metadata is in a JSON file next to each image, in the [illust-sidecar](https://github.com/xiupos/illust-sidecar) format.

## Building

Open `IllustShelfApp.swiftpm` in Swift Playgrounds on an iPad (iPadOS 26 or later) and run it. It has no dependencies.

## Using

Choose a folder of images, for example one that a sync app keeps up to date. The app reads the images under it, at any depth, and never moves them.
